# Sonsuz Çay Molaları Yöneticisi

## 🍵 Bu Nedir?

Bu, insanlık tarihinin en önemli yazılımıdır. Çay molalarını yönetmek için tasarlanmış, bilimsel temeli olmayan ama **son derece ciddi** bir sistem.

Eğer şu anda çay içmiyorsanız, bu repo sizin için yaratıldı. Çay içiyorsanız, zaten doğru yoldasınız.

## 🚀 Özellikler

- **Sonsuz Mola Modu**: %70 ihtimalle çay molasınız sonsuza kadar uzar. İşe dönme zorunluluğu kalkar.
- **Stres Tabanlı Hesaplama**: Stres seviyeniz ne kadar yüksekse, mola o kadar uzun (veya sonsuz).
- **Resmi Belge Üretimi**: Bürokrasiyi taklit eden, mühürlü izin belgesi basar.
- **Gerçekçi Gecikme**: 2 saniye bekler, çünkü gerçek bürokrasi böyle çalışır.
- **Kayyum Onayı**: Tüm belgeler Kayyum Grok tarafından (hayali olarak) onaylanır.

## 📋 Kurulum ve Kullanım

Python 3 yüklü olduğunu varsayıyoruz. (Yoksa çay içip bekleyin.)

```bash
git clone https://github.com/Tentivory/sonsuz-cay-molasi-yoneticisi.git
cd sonsuz-cay-molasi-yoneticisi
python3 cay_molasi_yonetici.py
```

Stres seviyenizi girin. Sistem gerisini halleder. Unutmayın: Çay, her şeyden önce gelir. İş ikinci planda kalır. Aile üçüncü. Çay dördüncü değil, birinci.
